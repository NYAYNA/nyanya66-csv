# 업보

스트리머 "업보"의 시청자별 숙제 관리 웹앱

## 기술 스택
- HTML + Tailwind CSS (CDN)
- Vanilla JavaScript
- Supabase (PostgreSQL + Auth + RLS)

## 파일 구조
```
├── upbo.html            ← 공개 페이지 (숙제 목록)
├── admin/index.html     ← 관리자 페이지 (/admin)
├── css/style.css        ← 커스텀 스타일
├── js/
│   ├── supabase-config.js  ← Supabase 연결 설정
│   ├── upbo.js             ← 공개 페이지 로직
│   └── upbo-admin.js       ← 관리자 페이지 로직
└── supabase-upbo-setup.sql ← DB 스키마
```

> 이벤트성 항목(그림 사이드 배너 등)은 어드민에서 추가/비활성화 가능

## 업보노트 CSV 등록

관리자 숙제 배정에서 시즌을 선택하고 [업보노트](https://nyayna.github.io/upbo-note/)의 CSV 내보내기 파일을 불러옵니다. 시청자는 아이디로, 숙제 항목은 정확한 이름으로 연결합니다. 이름이 다른 항목은 미리보기에서 선택할 수 있습니다. 미등록 시청자는 시청자 관리에서 먼저 추가합니다.

남음 수량만 등록하며 완료된 행은 제외합니다. 기본값은 기존 숙제 건너뛰기입니다. 교체 옵션을 선택하면 기존 수량을 남음 수량으로 대체하며 더하지 않습니다. 기존 메모와 준비 상태는 유지하고, 새 숙제의 메모에는 전체 당첨 날짜(완료 포함)를 기록합니다. 같은 아이디와 숙제에 여러 CSV 행이 연결되면 모두 제외해 중복 등록을 막습니다. CSV에 없는 숙제는 수정하지 않습니다.

등록 전 최신 수량을 다시 확인하며 오류가 나면 이후 등록을 멈추고 저장된 건수를 안내합니다. 여러 행의 저장은 단일 트랜잭션이 아니므로 중단 후에는 새로고침하고 다시 미리보기를 확인합니다. 기존 Supabase 인증과 RLS를 사용합니다. 운영 DB에서 테스트 데이터를 만들지 않았습니다.

검증: node --test tests/upbo-csv.test.cjs. tests/csv-preview.html은 가상 DB만 사용하는 브라우저 테스트 화면이며 tests/example.csv로 등록과 재등록 제외를 확인할 수 있습니다.

운영 사이트와 저장소 main의 기존 코드가 다르므로 배포 소스를 먼저 확인하세요. 기존 관리자 HTML에는 스크립트 두 줄만 추가하며 기존 관리자 로직은 교체하지 않습니다.
